¿Cómo funciona?

El código fuente entra al analizador léxico, que lo recorre carácter por carácter con los patrones definidos. Cada coincidencia produce un token en la tabla; lo que no coincide con ningún patrón es un error léxico. Un generador (Lex, Flex) construye ese analizador a partir de las reglas.

Componentes léxicos

  
Son las categorías del lenguaje (identificador, número, operador…) a las que pertenece cada lexema.

  






  
Patrones y lexemas

  
El patrón es la expresión regular que describe una categoría; el lexema es el texto concreto que la cumple.

  






  
Tabla de tokens

  
Registro ordenado de cada token con su lexema, posición y atributo (valor numérico o entrada en la tabla de símbolos TS).

  






  
Errores léxicos

  
Un error léxico ocurre cuando una secuencia de caracteres no cumple ningún patrón válido.
